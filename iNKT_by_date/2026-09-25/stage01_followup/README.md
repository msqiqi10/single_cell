## 已出现的具体线索

骨髓 C0 的 Junb、Fos、Dusp1、Fosb、Jun、Fosl2、Nr4a1 在 T2 较高，且通过现有基因 FDR。它们适合作为首个可追溯的功能整理示范，但不是证明整条 MAPK 通路被激活。

同一群的 MAPK 在两种既有输入口径下都未过通路 FDR：paper 规则约 0.078，robust 规则约 0.627。不能靠换口径把它包装成显著结果。下一步要检查完整功能模块的成员、方向和解释，而不只是追求一个星号。

Rorc、Il23r 的亚型标记作用与 T2 / Ctrl 的响应不同；当前这些条件比较并没有自动证明 C5-2 的 IL-17 分泌增强。Ccr6、Il17a、Il17f 缺于当前受检特征集，需要完整特征对象。
