# 验证范围与方法边界

## 实际验证

- 输入快照：1,334 个文件逐个 SHA256 与远端清单一致；主 AnnData 为 15,532 × 10,670。
- 离线复算：骨髓 C0 的 17,912 项原 GO 检验中，M/K/n/k 与命中基因逐项一致，P/FDR 差异仅为浮点精度。
- 本轮主输入：20 × 10,670 = 213,400 条 DE 记录与既有源表一致；更广的 26 份既有 DE 共 277,420 条完整保留。
- 覆盖：120 个 unit/direction/namespace 组合逐项核对候选数、命中集合、补集及家族内 BH。
- 网络：97 个节点、577 条边；节点 ID、嵌入、邻接矩阵与实际留出划分一致，所有边满足所声明的 Jaccard/共享基因规则。
- GNN：保留上游编码器结构；修正负样本抽样。验证/测试负样本唯一且互斥，均排除全部真实边；训练负样本还排除留出负样本。未向训练邻接矩阵加入留出正边。修正记录见 provenance/gnn_adapter.patch。
- 基线：语义余弦、共同邻居及 Adamic–Adar 在相同测试边上计算；图基线只用训练边。57 正/57 负的小型平衡留出集不代表真实边出现率。
- 回溯：每个模块 driver 的基因方向、基因 FDR、效应和所属 GO 逐项核对；未把组层面的计数当作新的组层面 P 值。
- 完整特征：原始 barcode 与保留细胞 ID 对齐、整数非负计数检查、逐群分子/分母加总与全局一致。Il17a 的“零检出”限定在最终保留细胞。
- 图形：五张图已视觉检查；已修正覆盖图图例重叠及 Il23r 最高柱的显示范围。主图同时提供 PNG、SVG、PDF。

## 统计与解释检查（11/11 已检查）

| 项目 | 本轮处理及剩余限制 |
|---|---|
| Simpson / 组织混合 | 同时保留组织整体与群内结果，图按组织×群展示；整体与群内不同方向不强行合并。未将整个数据的方向外推到每个群。 |
| 生态层面外推 | 群均值/GO 富集不推断每个细胞都有该功能；模块成员富集不等于每个细胞中复合体活性。 |
| 选择偏差（Berkson） | 原 QC、基因 min_cells=100、每组≥20，以及 GO 5–500 大小过滤均保留并说明；恢复完整特征用于检测审计，不声称消除选择偏差。 |
| Collider / 条件化偏差 | QC 匹配只作技术敏感性，可能对真实生物状态相关变量条件化；不把匹配结果当作因果调整。 |
| 基础比例忽略 | marker 同时报告检测细胞数和总数；GNN 说明人工平衡正/负留出及小样本量，不报告部署预测价值。 |
| 回归均值 | 无独立纵向复测；相同数据上的筛选、融合和重抽样不能充当复现。 |
| 幸存者/保留偏差 | 原始输入与保留细胞检测同时列出；零检出限定范围。没有只保留成功模型种子。 |
| 多重查找 | 全 DE、全 GO 家族与非显著条目保留；基因 BH、GO 家族 BH、跨 condition 分析 BH 分开。网络只取显著 BP 的筛选本身不产生独立验证。 |
| 分析路径自由度 | 主规则、排除前缀、α、k 范围、三种子均记录。分组是探索性的，未预注册，也未按是否找回专家假说挑最佳种子。 |
| 相关与因果 | RNA、富集、图重建不等于蛋白活性、分泌、杀伤或代谢通量；共享基因、ontology 祖先关系和专家假说三种关系分开。 |
| 逆因果/时间顺序 | 无足够时间序列/干预信息，未指定 AP-1→细胞毒性或折叠→功能的因果方向。 |

**不能由计算检查关闭的限制：** 每个样本标签混合三只小鼠，但无法识别独立动物/pool 重复。所有既有细胞层面显著性仍是探索性证据；20 次匹配抽样不产生 20 个生物重复。因而没有为这些结果标注“已完成生物学验证”。
